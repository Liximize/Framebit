# Security reports

Please avoid posting passwords, account tokens, signing keys, private recordings or exploit details in public issues.

If this repository offers **Security → Report a vulnerability**, use that private reporting route. Otherwise, open an issue titled **Private security contact requested** without sensitive details; the maintainer can arrange a private channel. No response deadline or security-support period is promised.

Include the affected version, a description of impact and reproducible steps when a private channel is available. Use a disposable recording and remove personal information from logs.

For ordinary bugs and capture problems, use the [issue forms](https://github.com/Liximize/Framebit/issues/new/choose).
